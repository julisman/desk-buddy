Desk Buddy

Install the Desk Buddy firmware on an ESP32-S3 straight from your browser. No software to install, no coding.

This browser isn't supported. Use Google Chrome or Microsoft Edge on a laptop/PC (not a phone). This page must be opened over https.
  1. First build it following the PDF build guide (LCD, knob, buzzer, touch wire).
  2. Plug the ESP32-S3 into your laptop with a USB-C data cable (not a charge-only cable), into the USB port (not COM).
  3. Click Install Desk Buddy, pick the port that appears (usually "USB JTAG/serial debug unit"), then Install. Wait about 1 minute.
  4. Press the RST button on the board. The screen flashes red-green-blue, then the face appears.
  5. On your phone, join the WiFi DeskBuddy-XXXX (the screen shows "WiFi setup: join DeskBuddy-XXXX, then open 192.168.4.1"). The setup page opens by itself; if not, open 192.168.4.1.
  6. Pick your home network under WiFi name, enter the Password, set Time zone and Weather location, then tap Save & connect. Done!

Port doesn't show up? Try another cable (many USB-C cables are charge-only), or hold the BOOT button, press RST, release BOOT, then click Install again. Change WiFi: hold the knob while powering on Desk Buddy until "WiFi reset" appears.
