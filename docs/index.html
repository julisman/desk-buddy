Desk Buddy

Install firmware Desk Buddy ke ESP32-S3 langsung dari browser. Tanpa install software, tanpa coding.

Browser ini belum bisa. Pakai Google Chrome atau Microsoft Edge di laptop/PC (bukan HP). Halaman harus dibuka lewat https.
  1. Rakit dulu sesuai panduan PDF (LCD, knob, buzzer, kabel touch).
  2. Colok ESP32-S3 ke laptop pakai kabel USB-C data (bukan kabel cas saja), di port USB (bukan COM).
  3. Klik Install Desk Buddy, pilih port yang muncul (biasanya "USB JTAG/serial debug unit"), lalu Install. Tunggu sekitar 1 menit.
  4. Tekan tombol RST di board. Layar berkedip merah-hijau-biru, lalu muncul wajah.
  5. Di HP, sambung ke WiFi DeskBuddy-XXXX (namanya tampil di layar). Halaman setup terbuka sendiri; kalau tidak, buka 192.168.4.1.
  6. Pilih WiFi rumah, isi password dan zona waktu, lalu Simpan. Selesai!

Port tidak muncul? Coba kabel lain (banyak kabel USB-C cuma untuk cas), atau tahan tombol BOOT, tekan RST, lepas BOOT, lalu klik Install lagi. Ganti WiFi: tahan knob sambil menyalakan Desk Buddy.
