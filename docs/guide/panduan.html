Alat

Laptop/PC dengan Google Chrome atau Microsoft Edge (untuk install firmware). Tidak perlu solder untuk versi breadboard ini. Opsional: solder untuk header LCD supaya kontaknya awet.

Penting: board harus ESP32-S3 N16R8. Varian lain (N8, N8R2, ESP32 biasa) memakai memori berbeda dan firmware ini tidak akan jalan.

Wiring

Semua sinyal ke header kiri ESP32-S3. Listrik dibagi lewat jalur breadboard: pin 3V3 ke jalur +, pin G ke jalur −.

Langkah rakit

  1. Cabut USB. Tancap LCD, knob, dan buzzer di breadboard, masing-masing di baris sendiri.
  2. Kabel male-male: pin 3V3 ESP32 ke jalur +, pin G ke jalur −. Lalu VCC/+ tiap modul ke jalur +, GND/− ke jalur −.
  3. Kabel female-male: ujung female ke pin ESP32, ujung male ke baris pin modul, sesuai tabel.
  4. Touch pad: satu kabel ke GPIO 7. Ujung satunya dibiarkan bebas, atau tempel copper tape 2x2 cm (bisa dari balik casing plastik).
  5. Cek sekali lagi: tidak ada kabel ke pin 5V, jalur + dan − tidak tertukar.
LCD tanpa solder: pin header LCD sering kurang nempel. Tancap sedikit miring dan tahan pakai selotip supaya pin menekan dinding lubang.

Install firmware

Tanpa install software. Buka di laptop (Chrome atau Edge):

https://julisman.github.io/desk-buddy/

  1. Colok ESP32-S3 ke laptop pakai kabel USB-C data, di port USB (bukan COM).
  2. Klik Install Desk Buddy, pilih port yang muncul (biasanya "USB JTAG/serial debug unit"), lalu Install. Tunggu sekitar 1 menit.
  3. Tekan tombol RST di board. Layar berkedip merah-hijau-biru lalu muncul wajah.

Sambungkan ke WiFi

  1. Di bawah layar muncul nama hotspot, misalnya DeskBuddy-1A2B.
  2. Di HP, buka pengaturan WiFi dan sambung ke hotspot itu. Halaman setup terbuka sendiri; kalau tidak, buka 192.168.4.1.
  3. Pilih WiFi rumah, isi password, pilih zona waktu (WIB/WITA/WIT), lalu Simpan. Desk Buddy restart dan tersambung.
Ganti WiFi / pindah rumah: tahan knob sambil menyalakan Desk Buddy sampai muncul "WiFi direset". Kalau WiFi tersimpan gagal tersambung, hotspot setup juga terbuka sendiri.

Mau ubah kode? Source code lengkap ada di https://github.com/julisman/desk-buddy (PlatformIO).

Cara pakai

Tahan knob (± 1 detik) untuk ganti mode. Elus pad sentuh kapan saja: wajah senang, keluar hati, bunyi "purr".

FACE
Putar = dielus (senang, melirik). Tekan = boop (kaget).
FOCUS
Putar = atur menit. Tekan = mulai / jeda. Fokus 25 menit lalu istirahat 5 menit otomatis.
CLOCK
Jam, tanggal, dan cuaca lokasi kamu.
CLAUDE
Status Claude Code dari laptop. Putar = pindah sesi. Tekan = diamkan alarm.

Tidak disentuh 5 menit (malam 23:00–07:00: 1 menit): Desk Buddy tidur dan layar redup. Sentuh knob untuk membangunkan.

Mode CLAUDE (untuk pengguna Claude Code)

Desk Buddy menampilkan model, context %, limit sesi (5 jam) dan mingguan beserta jam reset, dan status: WORKING, NEEDS YOU (alarm + bingkai merah saat Claude minta izin), DONE. Bisa memantau sampai 4 sesi sekaligus.

  1. Laptop dan Desk Buddy di WiFi yang sama. Butuh jq (brew install jq).
  2. Download source code dari https://github.com/julisman/desk-buddy, lalu jalankan tools/install-claude-hooks.sh. Lepas lagi: --uninstall.
  3. Buka sesi Claude Code baru. Coba tanpa Claude: tools/claude-desk-buddy.sh demo.

Yang dikirim ke Desk Buddy cuma angka dan status. Prompt dan balasan Claude tidak pernah keluar dari laptop.

Kalau ada masalah

GejalaSolusi
Layar menyala tapi abu-abu / putih polosKabel data LCD (SDA, SCL, CS, DC, RES) tidak nempel. Tancap ulang, miringkan sedikit header LCD di breadboard, tahan pakai selotip, tekan RST. Solder header LCD = solusi permanen.
Layar mati totalVCC LCD harus ke 3V3, bukan 5V (pin 5V tidak ada listrik saat colok USB native).
Board restart terus saat bunyiCek kabel buzzer: S ke GPIO 15, + ke 3V3, − ke GND. Firmware sudah memakai volume kecil supaya aman.
Port tidak muncul saat installGanti kabel USB-C (banyak yang cuma untuk cas). Coba port USB yang satunya. Atau tahan BOOT, tekan RST, lepas BOOT.
Knob kebalik / loncat 2Tukar kabel CLK dan DT. Kalau 1 klik = 2 langkah, beri tahu kami (setting firmware).
Jam / cuaca tidak munculWiFi belum tersambung. Tahan knob sambil menyalakan untuk setup ulang WiFi.
Elus tidak terasaJangan sentuh pad saat Desk Buddy menyala (kalibrasi). Pakai kabel pendek dan pad lebih lebar (copper tape 2x2 cm).
