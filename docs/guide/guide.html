Tools

A laptop/PC with Google Chrome or Microsoft Edge (to install the firmware). No soldering needed for this breadboard version. Optional: solder the LCD header so the contacts last.

Important: the board must be an ESP32-S3 N16R8. Other variants (N8, N8R2, plain ESP32) have different memory and this firmware will not run on them.

Wiring

All signals go to the left header of the ESP32-S3. Power is shared through the breadboard rails: pin 3V3 to the + rail, pin G to the − rail.

Do not use the 5V pin. When plugged into the native USB port, the 5V pin has no power. All modules use 3V3.

Assembly steps

  1. Unplug USB. Push the LCD, knob and buzzer into the breadboard, each in its own rows.
  2. Male-male wires: ESP32 pin 3V3 to the + rail, pin G to the − rail. Then each module's VCC/+ to the + rail and GND/− to the − rail.
  3. Female-male wires: female end on the ESP32 pin, male end in the module's pin row, as in the table.
  4. Touch pad: one wire to GPIO 7. Leave the other end free, or stick on 2x2 cm of copper tape (it works through a plastic case).
  5. Double-check: no wire on the 5V pin, and the + and − rails are not swapped.
LCD without soldering: the LCD header pins often make poor contact. Insert it slightly tilted and hold it with tape so the pins press against the sides of the holes.

Install the firmware

No software to install. On your laptop, open (Chrome or Edge):

https://julisman.github.io/desk-buddy/

  1. Plug the ESP32-S3 into your laptop with a USB-C data cable, using the port labelled USB (not COM).
  2. Click Install Desk Buddy, choose the port that appears (usually "USB JTAG/serial debug unit"), then Install. Wait about 1 minute.
  3. Press the RST button on the board. The screen flashes red-green-blue, then the face appears.

Connect to WiFi

  1. The bottom of the screen shows the setup banner WiFi setup: join DeskBuddy-XXXX / then open 192.168.4.1, where XXXX is your device's code, e.g. DeskBuddy-1A2B.
  2. On your phone, open the WiFi settings and join that hotspot. The setup page opens by itself; if it doesn't, open 192.168.4.1 in the browser.
  3. Fill in WiFi name (your home WiFi), Password, Time zone (e.g. WIB/WITA/WIT) and Weather location (your city), then tap Save & connect. The page shows Saved, Desk Buddy restarts and connects.
Changing WiFi / moving house: hold the knob while powering on Desk Buddy until WiFi reset appears. If the saved WiFi fails to connect, the setup hotspot also opens by itself.

Want to change the code? The full source is at https://github.com/julisman/desk-buddy (PlatformIO).

How to use

Hold the knob (about 1 second) to change mode. Pet the touch pad any time: the face gets happy, hearts pop out, and it "purrs".

FACE
Turn = petting (happy, glancing). Press = boop (surprised).
FOCUS
Turn = set minutes. Press = start / pause. Focus for 25 minutes, then a 5-minute break starts automatically.
CLOCK
Time, date and weather for your location. Before WiFi is set up it shows WiFi setup (see below).
CLAUDE
Claude Code status from your laptop. Turn = switch session. Press = silence the alarm.

Untouched for 5 minutes (at night, 23:00–07:00: 1 minute), Desk Buddy goes to sleep and dims the screen. Touch the knob to wake it.

CLAUDE mode (for Claude Code users)

Desk Buddy shows the model, context %, session (5-hour) and weekly limits with their reset times, and the status: WORKING, NEEDS YOU (alarm + red frame when Claude asks for permission), DONE. It can track up to 4 sessions at once.

  1. Laptop and Desk Buddy on the same WiFi. Requires jq (brew install jq).
  2. Download the source code from https://github.com/julisman/desk-buddy, then run tools/install-claude-hooks.sh. To remove it: --uninstall.
  3. Start a new Claude Code session. To try it without Claude: tools/claude-desk-buddy.sh demo.

Only numbers and status are sent to Desk Buddy. Your prompts and Claude's replies never leave your laptop.

Troubleshooting

SymptomFix
Screen lights up but is plain grey / whiteThe LCD data wires (SDA, SCL, CS, DC, RES) aren't making contact. Re-seat them, tilt the LCD header slightly in the breadboard, hold it with tape, press RST. Soldering the LCD header is the permanent fix.
Screen completely deadLCD VCC must go to 3V3, not 5V (the 5V pin has no power when plugged into native USB).
Board keeps restarting when it beepsCheck the buzzer wiring: S to GPIO 15, + to 3V3, − to GND. The firmware already uses a low volume to be safe.
Port doesn't appear when installingSwap the USB-C cable (many are charge-only). Try the other USB port. Or hold BOOT, press RST, release BOOT.
Knob reversed / jumps by 2Swap the CLK and DT wires. If 1 click = 2 steps, let us know (firmware setting).
No clock / weatherWiFi isn't connected yet (clock mode shows WiFi setup (see below)). Hold the knob while powering on to redo WiFi setup.
Petting isn't detectedDon't touch the pad while Desk Buddy is powering on (calibration). Use a short wire and a wider pad (2x2 cm copper tape).
